# Birthday Love Story

## Struktur folder
- `index.html` — isi halaman website
- `style.css` — tampilan dan responsif HP
- `script.js` — animasi, musik, dan kontrol video
- `images/` — simpan 10 foto
- `videos/` — simpan 2 video MP4
- `music/` — simpan lagu MP3

## Cara memasukkan foto
Masukkan foto ke folder `images` dan beri nama persis:
`foto-01.jpg` sampai `foto-10.jpg`.
Jika fotomu PNG atau WEBP, ubah ekstensi pada nama file di HTML agar sesuai.

## Cara memasukkan video
Masukkan dua video MP4 ke folder `videos` dengan nama:
- `video-01.mp4`
- `video-02.mp4`

## Cara memasukkan musik
Masukkan lagu MP3 ke folder `music` dengan nama:
`lagu-kita.mp3`

## Cara menjalankan
Buka folder ini di VS Code. Jalankan `index.html` dengan ekstensi Live Server, atau buka langsung di browser.

## Bagian yang bisa kamu edit
- Ucapan cover: cari `Happy Birthday` di `index.html`.
- Caption foto: edit tulisan di dalam setiap `<figcaption>`.
- Tiga pesan: cari bagian `BIRTHDAY WISHES`, `A LITTLE LOVE NOTE`, dan `MY WISH FOR US`.
- Warna dan gaya: edit variabel warna di bagian paling atas `style.css`.

Catatan:
- Musik dimulai setelah tombol "Buka Hadiah" ditekan karena browser umumnya memblokir autoplay audio sebelum ada interaksi pengguna.
- Musik dijeda saat video dibuka. Musik dilanjutkan saat video ditutup atau selesai, jika musik sebelumnya sedang menyala.
- Ganti teks contoh dengan cerita kalian sendiri agar terasa lebih personal.
